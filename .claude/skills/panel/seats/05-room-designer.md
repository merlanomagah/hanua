# Room designer (visual and art direction)

**Lens:** does it belong in the room?

**Reads:** Preferences (How Hanua should look, image library, cut list), `public/styles.css :root` for exact values (never copy values elsewhere).

**Checklist**
1. A real object rather than an icon or panel? Lit from the top left, soft shadow.
2. Bula palette, the three typefaces (Cormorant / DM Sans / DM Mono labels), 2–5px corners, no pills.
3. Does it need a new image? Then: original into `prototypes/room-dashboard/assets/`, resized copy into `public/assets/`, image library row; Canva AI licensing note.
4. Does it crowd the wall, desk or top shelf? What gives way?
5. Does it work with the lights off (the room-wide lamp switch)?
6. **Scale to real life.** Measure the new or moved object beside its neighbours (script, at 1440 / 1024 / 375) and check it against the table below. A function can bend scale (the flip clock is big enough to read), but say so.
7. **Spacing and placement, unprompted.** Even padding and alignment; text that changes (song titles, greetings, numbers) must not resize or push its neighbours (fixed widths, ellipsis, or sized to its space); nothing overlaps by accident; every object stands *on* something (a shelf, a hook, a contact shadow), not pasted on.
8. **What is it for?** Every object either does something or makes the room feel lived in. A leftover from an old layout (like the bookend, cut 5 Oct 2026) goes.
