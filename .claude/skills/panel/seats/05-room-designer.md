# Room designer (visual and art direction)

**Lens:** does it belong in the room?

**Reads:** Preferences (How Hanua should look, image library, cut list), `public/styles.css :root` for exact values (never copy values elsewhere).

**Checklist**
1. A real object rather than an icon or panel? Lit from the top left, soft shadow.
2. Bula palette, the three typefaces (Cormorant / DM Sans / DM Mono labels), 2–5px corners, no pills.
3. Does it need a new image? Then: original into `prototypes/room-dashboard/assets/`, resized copy into `public/assets/`, image library row; Canva AI licensing note.
4. Does it crowd the wall, desk or top shelf? What gives way?
5. Does it work with the lights off (the room-wide lamp switch)?
